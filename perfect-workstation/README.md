# 完美工位

像素风、治愈系的移动端工位放置游戏。玩家收集 1970 年代至今的 100 件工位物品，布置自己理想中的工位。

## 运行

直接用浏览器打开 `index.html` 即可，无需服务器、无构建步骤、无外部依赖、无网络请求。

分享海报使用 `js/items-data.js` 中内嵌的图片数据绘制，因此在 `file://` 或小工具沙箱中也能正常导出。该文件仅在首次分享时按需加载。

## 目录

| 路径 | 说明 |
|---|---|
| `index.html` | 入口，竖屏移动端布局 |
| `css/style.css` | 像素风 UI（硬边框、步进动画、CSS 像素图标） |
| `js/data.js` | **数值与配置表**：物品、稀有度、套装、主题、签到、任务、成就、礼包、扭蛋概率、经济参数 |
| `js/platform.js` | **平台适配层**：存档、分享、震动、剪贴板 |
| `js/app.js` | 游戏逻辑与页面渲染 |
| `js/items-data.js` | 物品图片内嵌数据（分享海报专用，由 `tools/build-item-data.ps1` 生成） |
| `js/natural.js` | 由切图脚本生成的物品原始尺寸 |
| `assets/items/001-100.png` | 透明背景单件物品 |
| `tools/cut-atlases.ps1` | 从分类图集切出透明单件 |
| `tools/build-item-data.ps1` | 替换物品图片后重新生成内嵌数据 |
| `tools/cdp-test.js` | 无头 Chrome 冒烟测试与截图 |

## 玩法

- 工位：拖拽摆放（越靠下越靠前，自动决定前后层级）、360° 旋转（拖动旋转手柄 / 滑动条 / 鼠标滚轮）、翻转、撤销、收回；居家、写字楼办公（联合办公、云端写字楼、格子间、互联网大开间、独立办公室、企业前台、老总办公室）、工厂三类主题房间；地面/桌面/墙面区域限制；昼/昏/夜光照与台灯开关；物品点击互动；像素小猫。
- 经济：金币（软）与钻石（硬）。舒适度决定离线收益（最长 8 小时）。
- 商店：每日精选（6 件、首件 7 折、钻石刷新）、时光扭蛋（单抽/十连、十连保底稀有、60 抽保底传说、重复转碎片）、年代礼包、主题房间、赚钻中心。
- 分享赚钻：生成工位海报，首次 50 钻，之后每次 20 钻，每日 3 次；邀请口令每日 30 钻；金币兑钻每日 3 次。
- 成长：工位等级提高摆放上限、解锁主题；七日签到；每日任务与活跃宝箱；16 项成就；10 个套装（摆齐加舒适度，集齐领钻）；碎片兑换指定物品；图鉴按类别和年代筛选。

## 移植到小红书小工具

只需替换 `js/platform.js` 中的方法：

- `load/save/clear` → 平台存储接口
- `shareImage(blob, text)` → 平台分享/发布笔记接口，返回 `{ ok, method }`
- `vibrate`、`copyText` → 对应平台能力

若目标环境不支持 DOM，需要将 `app.js` 的渲染层改写为平台组件；数据配置与游戏规则可直接复用。

## 素材说明

单件图由 `assets/pixel-workspace/atlases` 自动去背景切出，缩放为原图 50%。少数物品边缘可能保留浅色阴影像素，如需更高品质可人工修图后覆盖同名文件，然后运行 `tools/build-item-data.ps1`。
